# 升级说明

从 preview.24 开始提供。更早的安装包仍使用手动升级；GitHub 发布与公开版本间完整升级验收分别进行。

## 提醒与版本说明

安装版启动且网络可用时检查固定 `morrowfactory/istart` 公开 GitHub Releases；成功后六小时再检查，失败后十五分钟重试。网络恢复可触发检查，距上次尝试至少两分钟。网卡可用不等于 GitHub 可达，请求失败仍可使用当前版本。

发现新版后，主菜单“设置”和设置内升级入口同时显示小红点，并提供文字及辅助说明。打开升级页不会清除提醒。“版本与升级”位于设置顶部，页面展示：

- 当前安装版本和目标版本。
- 发布者在 GitHub 说明的变化及新增功能，保留原文语言。
- 实际下载进度、校验及安装状态。

未提供说明时明确提示；说明最多 12,000 字，过滤已知技术来源尾注。预览版接受更高预览或正式版，正式版仅接受正式版。

## 自动或手动

**默认勾选自动升级**，旧配置未保存该选项时同样默认开启。勾选立即保存，不需要再点击通用保存设置按钮。

| 方式 | 下载 | 安装 |
| --- | --- | --- |
| 勾选 | 后台下载并校验 | 等待菜单隐藏、没有设置/升级/截图窗口，当前 Windows 会话空闲至少一分钟 |
| 取消勾选 | 只提醒，用户点击下载 | 用户点击安装，打开完整向导 |

切换手动会取消自动下载并保留红点。手动模式关闭升级页取消下载，自动模式关闭页面后继续下载。退出 iStart 会取消待完成检查/下载，并丢弃迟到结果。

自动安装仍显示安装进度窗口，不重启 Windows、不强制关闭其他软件。执行前再次校验安装包，并重新判断自动安装条件。安装器请求 iStart 正常退出；退出失败则停止安装。自动安装成功后在后台启动新版，保留原生/自定义开始菜单偏好、开机启动选择、个人入口、历史和有效设置。

只有带卸载程序的安装版可以执行安装；开发和 UI 测试运行不启动自动调度或执行安装器。没有新增 Windows 服务、驱动、计划任务或界面依赖。

## 来源、隐私与缓存

- 仅接受固定仓库的精确版本名 x64 资产，拒绝草稿、外部 URL、非法版本及缺失 SHA256 的资产。
- 检查预算三十秒、100 个版本、响应 2 MiB；下载预算十五分钟、256 MiB。大小/SHA256 一致才从 .part 改为 exe，安装前再次校验。
- 不向 GitHub 上传软件列表、路径、浏览历史或截图。空闲判断仅读取当前会话距离上次输入的时间，不记录按键。
- 失败/取消只清理本次临时数据；下载成功后仅清理已知更新缓存中超过七天的旧文件，至少保留最近两次下载，不触碰个人配置。
- 安装包仍未签名，TLS 和校验值不能替代发布者签名；不能保证任意安装失败都完整恢复旧版本。

## 验证范围

2026-10-17 当前 Windows 11 构建为零警告/错误，已有回归及隔离更新流程/界面检查通过。夹具覆盖默认与保存、断网/恢复、检查共用、手动仅提醒、自动延后安装、切换模式/退出取消、迟到结果、安装前篡改及重下、安装参数、两处红点、版本说明和中英文 Windows/Google 渲染，不执行夹具安装器。

独立 QA 安装器在新测试目录验证首次、带自动更新参数覆盖和卸载；跳过生产退出/重启操作，不覆盖日常安装。

未来公开版本间完整升级、生产安装后成功重启、交互取消、文件占用、磁盘不足、安装中断、Win10/其他 Win11 仍需验收，不能以模型或 QA 检查替代。详见[架构](ARCHITECTURE.md)及[发布流程](GITHUB_RELEASE.md)。
