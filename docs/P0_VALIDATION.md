## 接入决策与下一步

当前采用不接管系统入口的验证窗口。任务栏按钮自动化定位可以作为候选取证路径，但仅定位成功不足以选择拦截方案。

下一步在隔离桌面环境验证：按钮边界与多屏更新、Win 组合键保留、原生菜单交接、退出及异常恢复，再决定系统适配实现。微软说明低级键盘钩子可能因超时被移除，不能把钩子安装成功当作可靠接入结论。[官方说明](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelkeyboardproc)

Open-Shell 根许可证通过 GitHub API 确认为 MIT，当前未复制或链接其代码。后续如采用，仍需对固定提交及其第三方组件逐项检查。[源码许可证](https://github.com/Open-Shell/Open-Shell-Menu/blob/master/LICENSE)

## 验证包使用

解压完整 ZIP，运行 `IStart.App.exe`。可以手动添加文件、拖入入口、创建和拖动分类、双击入口打开；右键软件候选可固定或移除，拖到收藏可添加。关闭窗口即退出。程序不添加开机启动、不接管开始按钮、不修改登录或电源设置。

仅提供独立运行技术验证包；正式安装向导仍按执行计划等待系统恢复门槛通过后开发。构建临时文件与本地验证产物在 `artifacts/` 中，未写入生产服务器；CI 产物保留 7 天。无生产备份或发布包需要清理。
